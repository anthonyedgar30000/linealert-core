How to use this reference

  1. Start with the issue LineAlert routed.
  2. Use current evidence and CMMS history to rank the standard action.
  3. Operator performs one routine bounded action.
  4. Run a fresh verification before another material change.
  5. Escalate only when the evidence or physical task falls outside the routine operator envelope.
Demo authority assumption All actions listed below are commissioned to the operator in this synthetic plant by default. A real plant can override any action by asset, state, role, prerequisite, or safety condition.

Default operating rule

  • Use evidence and history to rank the ordinary action.
  • Make one material change at a time.
  • Give the machine/process time to express the result.
  • Capture the fresh evidence automatically where possible.
  • Rerank after every bounded trial.

Escalate when

  • The standard change does not improve the issue.
  • Evidence contradicts the familiar pattern.
  • The task requires access outside the normal operator position.
  • Mechanical damage, unsafe conditions, or non-routine behavior appears.

Evidence discipline

  • Historical pattern ≠ current root cause.
  • Strong match ≠ proof.
  • Operator action ≠ unrestricted discretion.
  • Successful trial ≠ safe production change.
