Controlled reference for understanding visible labeling issues, bounded checks, escalation conditions and the operational knowledge behind a LineAlert procedure route.

How to use this controlled reference

  1. Start from the procedure routed by the active LineAlert workflow.
  2. Review the checks and related issue areas without assuming root cause.
  3. Perform only the inspection or task allowed for your role.
  4. Return to LineAlert and record what the current inspection established.
  5. Continue, validate or escalate through the assigned operational authority.
WHAT IS THE ISSUE YOU ARE SEEING?
↓↓↓↓↓
1

Label Alignment Is Off

Examples

  • Crooked label
  • Rotated label
  • Inconsistent placement
  • Drifting placement
  • Skewed left/right

Checks

  • Peel tip square to bottle?
  • Is bottle stable during application?
  • Are guide rings centered?
  • Is issue constant or intermittent?
  • Does issue worsen at higher speed?

Actions

  1. Adjust Peel Angle
  2. Adjust Hold Down
  3. Check Guide Rings
  4. Increase Label Delay
  5. Reduce Speed Temporarily
Key Point

Alignment problems are usually caused by geometry, stability, or timing offset.

▸ Simulate this pattern Late label feed / placement drift

Inject this fault and watch Observed arrival drift out of its envelope — then compare LineAlert's suggested adjustment to Peel Angle / Hold Down.

2

Label Has Folds

Examples

  • Wrinkles
  • Folded edges
  • Label bunching
  • Uneven application

Checks

  • Is label speed too high?
  • Is aligner speed too slow?
  • Are folds random or consistent?
  • Does reducing speed help?

Actions

  1. Decrease Label Speed
  2. Increase Aligner Speed
  3. Verify Product Stability
  4. Reduce Conveyor Speed
Key Point

Folds are usually caused by speed mismatch or poor label settling.

▸ Simulate this pattern Unstable bottle spacing

Watch RPM stability and Arrival coordination fall out of sync in the Machine relationship panel before a Bounded finding appears.

3

Label Has Stretch Lines

Examples

  • Stretched label
  • Tension marks
  • Distorted print
  • Label pulling

Checks

  • Is label tension too high?
  • Does issue worsen at higher speed?
  • Are feed rollers pulling unevenly?

Actions

  1. Decrease Label Speed
  2. Increase Aligner Speed
  3. Inspect Feed Rollers
  4. Verify Label Tension
Key Point

Stretch lines are caused by excessive tension or feed speed mismatch.

▸ Simulate this pattern Excessive web tension / stretch

Watch Motor RPM and Residual widen together — the same speed/tension mismatch described in the Key Point.

4

Bubbles On Labels

Examples

  • Trapped air bubbles
  • Incomplete adhesion
  • Lifting label edges

Checks

  • Enough pressure time?
  • Is bottle stable?
  • Is contact pressure consistent?
  • Does slowing machine help?

Actions

  1. Increase Aligner Run-On
  2. Increase Bottle Pressure
  3. Decrease Label Speed
  4. Inspect Contact / Wipe Pressure
Key Point

Bubbles are caused by insufficient pressure time or unstable contact.

▸ Simulate this pattern Low contact pressure / bubbles

Watch the Pressure envelope and Contact pressure readout fall out of range in the Machine relationship panel.

5

Multiple Labels Applying

Examples

  • Double labels
  • Skipped gaps
  • Overlapping labels

Checks

  • Is sensor detecting gaps properly?
  • Is spacing consistent?
  • Is issue intermittent?
  • Does issue occur at specific speeds?

Actions

  1. Adjust Sensor Sensitivity
  2. Reposition Sensor
  3. Move Sensor Position
  4. Check Label Spacing
  5. Inspect Feed Timing
Key Point

Multiple labels are caused by sensor or feed timing issues.

▸ Simulate this pattern Gap-sensor retrigger / double label

Watch Evidence age and Finding lifecycle as the gap sensor double-triggers, then apply the suggested sensor adjustment.

How these issues are related

These problems can be caused by similar underlying factors. Adjusting one area may help more than one issue — this is the same relational logic LineAlert's Machine relationship panel checks automatically.

Folds⇄Stretch Lines

Speed or tension mismatch

Bubbles⇄Alignment Off

Insufficient pressure time or unstable contact

Stretch Lines⇄Multiple Labels

Feed / tension instability affecting sensor detection

General tips

  • Make one adjustment at a time
  • Allow time for the machine to stabilize
  • Verify results before making more changes
  • Keep sensors clean and properly positioned
  • Monitor issues at production speed

When to escalate

  • Issue continues after all adjustments
  • Multiple issues occurring at the same time
  • Issue worsens or returns quickly
  • Mechanical damage or worn parts
  • Unusual noises or air leaks
  • Need for replacement parts

Document & track

Record what you changed and the results. This helps identify patterns and prevents repeating the same steps.

  • Date / Time
  • Issue observed
  • Adjustments made
  • Result / Notes

Safety first

  • Follow all safety procedures. Never reach into moving equipment.
  • Lockout / Tagout when needed
  • Keep guards in place
  • Wear appropriate PPE

Controlled procedure reference

This guide preserves troubleshooting knowledge behind a routed LineAlert procedure. It explains candidate checks and escalation conditions; it does not diagnose the current machine or authorize an adjustment.

Governed workflow

  1. LineAlert qualifies the available evidence and publishes a bounded finding.
  2. A versioned rule routes the finding to one controlled procedure.
  3. The assigned role performs the displayed check within its authority.
  4. The inspection result is recorded in the active recovery workflow.
  5. Fresh evidence determines whether to continue, validate or escalate.
  6. Qualified human authority retains adjustment, safety and release decisions.
